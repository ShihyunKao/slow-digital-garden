# Both Hands V03.01: Cosmic Memory

## Question
Can a two-hand breathing gesture create a visual memory of expansion and return?

## Change from V02
V02 created a cosmic breathing field controlled by the distance between two hands. V03.01 keeps this spatial system but adds memory: when the hands open and then return, the system leaves behind a faint orbit-like trace.

## Interaction
Select **Begin** to activate the camera. The distance between both index fingers controls the field. Moving the hands apart opens the cosmos. Bringing them back together creates a memory ring.

The sketch starts in **Points** mode. `P` cycles hand visibility through **Points → Skeleton → Hidden**. `R` clears the memory rings. `?` opens or closes the help screen.

## Reading the archive

- Each complete opening-and-return cycle creates one orbit-like memory ring.
- Eight rings are placed from the outer field towards the centre in chronological order.
- The layered orbit lines make one completed breath visible as a spatial trace.
- Surrounding stars form the constellation-like atmosphere of each memory.

## Design intention
This sketch explores breathing as a visible cycle. The body does not draw directly; instead, it opens and closes a field, and each completed breath leaves a trace.

## Technical experiment
- Two-hand distance tracking
- Camera-first exhibition flow
- Breath cycle detection
- Persistent memory rings
- Layered orbit lines
- Fading star archives
- Help screen and hand-display controls

## What to observe
- Does the open-close cycle feel intentional?
- Do memory rings make the interaction more meaningful?
- Does this direction feel stronger than the trail-based sketches?
- Could this become the main visual system for the final project?

## Next development
Test a version where memory rings are affected by the quality of movement, such as speed, steadiness or symmetry.
