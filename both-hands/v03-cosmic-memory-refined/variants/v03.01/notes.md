# Both Hands V03.01: Amber Orbit

## Relationship to V03.00

The eight-cycle opening-and-return structure is retained, but drawn memory rings are replaced by warm orbital particles.

## Visual and interaction

Opening both hands releases gold and dark-red particles around their midpoint. Returning to the centre completes one long-lived particle memory, while the live particles continue to turn under the two-hand gravitational field.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the archive and `?` opens the field guide.

## Design intention

The version keeps the history of repeated breaths visible without revealing it as a set of rigid rings, using density, glow and slow drift instead.
