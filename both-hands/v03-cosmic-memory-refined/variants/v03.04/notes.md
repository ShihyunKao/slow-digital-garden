# Both Hands V03.04: Paper Eclipse

## Relationship to V03.00

The same eight-step opening-and-return archive is preserved, but its memories become layered cut-paper discs arranged along a diagonal composition.

## Visual and interaction

Opening reveals the paper layers progressively. Returning to the centre completes one sheet, which settles and compresses into a shallow embossed memory with fibre detail and a low side shadow.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the archive and `?` opens the field guide.

## Design intention

The version makes each stored cycle feel physical and archival while keeping the final form quiet enough not to disclose the full live effect in advance.
