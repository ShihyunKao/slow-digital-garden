# Both Hands V03.02: Frozen Constellation

## Relationship to V03.00

This version keeps the complete opening-and-return cycle but turns the accumulating memory into a persistent pale-violet crystalline mesh.

## Visual and interaction

Opening both hands expands the faceted field. Completing the return starts a new crystal layer; while the hands remain near the centre, further tracked positions continue adding connections, and each new segment grows into the persistent mesh. Camera proximity affects the visible span.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the archive and `?` opens the field guide.

## Design intention

The experiment translates bodily repetition into a restrained structural network rather than a smooth orbit, while preserving the layered memory of multiple cycles.
