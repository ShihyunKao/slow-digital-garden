# Both Hands V03.03: Lacquer Echo

## Relationship to V03.00

The original eight-memory cycle remains, but each completed breath becomes an offset black-lacquer layer instead of an orbit line.

## Visual and interaction

Opening widens a slow wet field. Returning to the centre creates one displaced lacquer slice, which cures over time while a narrow specular reflection travels across its surface.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the archive and `?` opens the field guide.

## Design intention

This version explores a darker, denser material memory whose movement remains visible through curing and reflection rather than through particles.
