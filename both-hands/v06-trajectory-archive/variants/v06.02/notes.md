# Both Hands V06.02: Afterimage Corridor

## Change from V06

The final joined-hand midpoint is still sampled as the anchor, while the session expands from eight to ten cycles. Each completed anchor is placed on a transparent smoked-glass pane. Every pane uses the same full positioning field, so later anchors can still reach the bottom and outer edges. When a new anchor appears, all older panes ease backwards towards the distant light, converting temporal order into spatial depth without shrinking the available coordinate range.

## Data mapping

- Chronological order → corridor depth
- Final joined-hand midpoint → full-pane position on every glass layer
- Open-palm pause → glass-pane brightness
- Movement steadiness → afterimage clarity

Stable movement leaves a compact, legible afterimage. Unstable movement spreads the same anchor into softer smoke-violet copies. No extra branches or independent marks are introduced.

After the tenth anchor settles, the path dims and then recalls the archive in order: a brighter line travels from anchor 01 to anchor 10, briefly illuminating every node it reaches.
