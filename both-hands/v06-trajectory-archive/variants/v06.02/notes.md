# Both Hands V06.02: Afterimage Corridor

## Change from V06

The near-closed joined-hand midpoint is still sampled as the anchor, while the session expands from eight to ten cycles. Each completed anchor is placed on a transparent smoked-glass pane. Every pane uses the same full positioning field, so later anchors can still reach the bottom and outer edges. When a new anchor appears, all older panes ease backwards towards the distant light, converting temporal order into spatial depth without shrinking the available coordinate range.

## Data mapping

- Chronological order → corridor depth
- Near-closed sampled midpoint → full-pane position on every glass layer
- Open-palm pause → glass-pane brightness and anchor-node size
- Movement steadiness → afterimage clarity

Stable movement leaves a compact, legible afterimage. Unstable movement spreads the same anchor into softer smoke-violet copies. No extra branches or independent marks are introduced.

An earlier description implied that the system waits for the tenth pane to settle completely. In the current version, recording the tenth anchor immediately dims the ordinary path and begins the chronological recall; older panes may still be easing backwards at that moment. A brighter line travels from anchor 01 to anchor 10, briefly illuminating every node it reaches.
