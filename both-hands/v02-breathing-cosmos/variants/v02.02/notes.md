# Both Hands V02.02: Cloud Chamber

## Relationship to V02.00

The same live two-hand breathing system is retained, but its field becomes mist, suspended dust and translucent air. The version does not save completed traces.

## Visual and interaction

Opening both hands increases the cloud's diffusion range. Fine particles drift through a softened oblique amber beam, and a residual air current dissolves after the hands return inward.

Select **Begin** to start the camera. `P` changes the hand display, `R` resets the live field and `?` opens the field guide.

## Design intention

This variation tests a less geometric reading of the gesture through layered density, blurred boundaries and lingering atmospheric motion.
