# Both Hands V04.01: Seismograph Skin

## Relationship to V04.00

V04.00 stores movement quality in rings. This version writes each complete opening and return as one horizontal graphite record, with room for twelve stored bands.

## Visual and interaction

Opening writes from the left edge to the centre; fully open is only the midpoint. Returning writes from the centre to the right and stores the band only when the return is complete. Slowness affects line density, instability affects jitter, hand tilt changes the band slope and a held pause leaves a darker terminal deposit.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the records and `?` opens the field guide.

## Design intention

The experiment makes the full temporal structure of one breath readable as a left-to-right trace rather than a single circular object.
