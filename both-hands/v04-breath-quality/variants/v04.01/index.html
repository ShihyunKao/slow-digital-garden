GESTURE STUDY 04.01  /  FIELD GUIDE

Seismograph Skin

A complete opening and return writes one graphite record.
The centre marks the fully open midpoint—not the end.

READING THE ARCHIVE

Read each band from left to right as one complete gesture. Opening writes the first half from the left edge to the centre. Fully open is the midpoint. Returning writes the second half from centre to right; only when the hands complete that return is the band stored. Slow motion becomes dense and continuous, instability fragments the trace, tilt changes its slope, and a held pause leaves a dark terminal deposit.

01

BEGIN / LEFT

Allow the camera and bring both hands together. The record begins at its left edge.

02

OPEN / CENTRE

Open slowly as the trace travels toward the centre. Fully open completes only the first half.

03

RETURN / RIGHT

Pause if desired, then return the hands together. The trace reaches the right edge and only then is stored.
