# Both Hands V04.02: Glass Strain

## Relationship to V04.00

This version keeps the same quality-based two-hand cycle but fixes each completed movement as a displaced transparent glass pane.

## Visual and interaction

Open both hands, pause if desired, then return them together to store the pane. Movement steadiness changes crack branching, signed hand tilt directs the stress pattern and the open-palm pause strengthens the central highlight. Fully open remains the midpoint of the cycle rather than its completion.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the panes and `?` opens the field guide.

## Design intention

The variation treats movement quality as internal material stress, allowing repeated gestures to accumulate as transparent but individually readable records.
