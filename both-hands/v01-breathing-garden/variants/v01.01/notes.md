# Both Hands V01.01: Woven Canopy

## Relationship to V01.00

This version keeps the same live two-hand distance gesture and does not save completed traces. It replaces the contour field with a suspended linen-like canopy.

## Visual and interaction

Touch the index fingertips, then open both hands slowly. The centre of the woven field opens first, while delayed outer fibre layers create a softer return when the hands come together again.

Select **Begin** to start the camera. `P` changes the hand display, `R` resets the live field and `?` opens the field guide.

## Design intention

The experiment tests whether the original breathing motion can feel soft and material through layered fibres, restrained colour and backlit cloth rather than drawn contour rings.
