# Open V04.02: Acoustic Compression

## Relationship to V04.00

This version preserves the opening-and-release trigger but translates the pressure bloom into a directional monochrome acoustic field.

## Visual and interaction

Opening the palm condenses an elliptical pressure slice. Reaching the open-palm threshold releases a stored wavefront through a bright flash, darkening edge, fracture and granular aftershock; closing the hand rearms the trigger. The direction follows the captured hand orientation.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the wave memories and `?` opens the field guide.

## Design intention

The variation tests a sharper temporal sequence—compression, release and decay—while retaining the same basic bodily action.
