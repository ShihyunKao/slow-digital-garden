# Open V01.02: Luminous Aperture

## Relationship to V01.00

The original open-palm expansion is retained, while the graphite-like field becomes a cold blue luminous aperture.

## Visual and interaction

Opening the palm expands high-contrast radial lines, concentric aperture rings and fine particles. Additive light, edge glow and a subtle pulse create the brighter optical response.

Select **Begin** to start the camera. `P` changes the hand display and `?` opens the field guide. This live version does not retain an archive that needs resetting.

## Design intention

This variation tests how light, contrast and pulse can make the same unfolding gesture feel spatial without changing its basic control.
