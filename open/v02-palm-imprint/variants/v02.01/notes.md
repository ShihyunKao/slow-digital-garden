# Open V02.01: Dust Negative

## Relationship to V02.00

The same fully opened-palm trigger is retained, but the imprint is formed by displaced charcoal dust rather than illuminated landmark points.

## Visual and interaction

Opening the palm pushes particles away from the hand shape and creates a temporary negative-space record. The dust then settles and slowly refills the cleared area. Relaxing the hand rearms the trigger independently, so a new imprint can begin while an older dust field is still refilling.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the imprints and `?` opens the field guide.

## Design intention

This version tests memory through absence: the hand is readable because material has moved away from it rather than because its outline is drawn.
