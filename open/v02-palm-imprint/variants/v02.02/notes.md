# Open V02.02: Cyanotype Exposure

## Relationship to V02.00

This version keeps the open-palm imprint trigger and turns each captured hand into a framed cyanotype specimen.

## Visual and interaction

Camera distance controls the specimen scale: a nearer hand produces a larger exposure and a farther hand a smaller one. Pale particles develop inside the frame, hold briefly and then wash back into Prussian blue. Multiple specimens can overlap during the session.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the exposures and `?` opens the field guide.

## Design intention

The experiment adds photographic time and physical scale to the temporary hand memory while preserving the original gesture threshold.
