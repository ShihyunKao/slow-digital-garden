# Trail V01.01: Ink Sediment

## Relationship to V01.00

This version keeps the same index-fingertip path and invisible flow field, but changes the fine line streams into wet ink deposits.

## Visual and interaction

Slow movement leaves diluted centres, feathered edges and irregular blooms. Fine sediment gains weight as it ages and settles through the accumulated drawing.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the drawing and `?` opens the field guide.

## Design intention

The experiment gives the trail a layered paper-and-ink memory in which the trace continues to change after the finger has passed.
