# Trail V01.02: Electric Drift

## Relationship to V01.00

The original fingertip path and flow-field movement are retained, while the drawn stream becomes a cold electric filament.

## Visual and interaction

Moving the index finger releases bright blue traces with short luminous afterimages, local flicker and small filament particles. The path remains layered but no longer uses wet diffusion or sediment.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the drawing and `?` opens the field guide.

## Design intention

This variation tests a faster visual energy and sharper light response without altering the slow bodily input that generates the trail.
