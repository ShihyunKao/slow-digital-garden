# Trail V02.02: Suspended Vapor

## Relationship to V02.00

The input cadence, movement threshold and pause detection match Soft Ink Wash, but the pale liquid wash becomes delayed volumetric vapour.

## Visual and interaction

Slow movement suspends a fine trace in the dark field. After a short delay, mist nodes swell, overlap and drift upward; stopping the hand allows the backlit cloud to keep gathering.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the vapour and `?` opens the field guide.

## Design intention

This variation tests whether delayed ascent and blurred density can make a two-dimensional trail feel atmospheric and spatial.
