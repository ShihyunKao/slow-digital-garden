# Trail V03.01: Surveyor’s Map

## Relationship to V03.00

The smoothing, point spacing, pause time and anchor cooldown of Path Constellation remain unchanged. Its dotted path becomes a printed survey record.

## Visual and interaction

Moving the index finger deposits measured points that connect after a short delay. Pausing registers a numbered marker surrounded by a small local contour reading on an off-centre paper map.

Select **Begin** to start the camera. `P` changes the hand display, `R` clears the map and `?` opens the field guide.

## Design intention

The experiment turns an expressive bodily path into a restrained system of measurement, location and recorded terrain.
